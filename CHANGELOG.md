# Changelog

## 1.0.1 — 2026-11-06
Documentation and licence update. The distribution now contains only the pre-generated LUTs and their documentation. The `.cube` files are byte-identical to 1.0.0 (same SHA-256 values in `MANIFEST_SHA256.txt`).

## 1.0.0 — 2026-11-06
First public release: 29 profiles, 28 unique curves, 203 LUTs in profile folders (196 unique tables) + 21 Sony viewfinder short-name copies = 224 `.cube` files (33³, −1 … −4 EV in half-stop steps). Per-file precision audit, RO/EN/ES documentation, portable and macOS-icons archives with SHA-256 checksums.
